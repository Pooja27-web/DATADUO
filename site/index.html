Process

What happens to your data

Four stages, in this order. The shape of particles behind the page changes with each one.

01 Load

Read the file and recognise the columns

Upload a file or paste a link. Column roles such as date, sales, product and region are recognised from their names, and you can correct any guess before the analysis runs.

Shown behind: scattered rows

02 Clean

Fix what can be fixed, and say so

Duplicate rows are removed. Columns that are mostly empty are replaced by a yes or no flag, and smaller gaps are filled with the median or the most common value. Every change is written to a log.

Shown behind: an ordered table

03 Analyse

Charts in the order people ask questions

Sales data gets six report pages. Any other table gets charts for the gaps in the data, the outcome you chose and the factors that matter most. Every chart has a one or two sentence note under it.

Shown behind: a bar chart

04 Predict and report

Models are compared with a plain guess

Several models are tested with 5-fold cross-validation. The report says in one sentence whether the best model is clearly better than guessing, and lists the factors it relies on.

Shown behind: a fitted surface with data points

Reports

Six report pages, one question each

Each page is a 16:9 layout with a column of key figures and a grid of charts. Pick a page to see what it contains.

Chart names are the ones built from a sales table. Key figures are shown as labels only.
